KSI Tools File Viewers

Drop a file onto a page. It is parsed and displayed entirely in your browser — classic ops formats, Terraform plans, kubeconfig, Kubernetes YAML, IAM policies, HAR, JWT/certs, archives, and more. Single HTML files you can open from disk, share on a USB stick, or host as static pages.

Browse viewers Privacy GitHub Documentation

Built for ops work

When the file might contain production config, customer exports, or credentials, the viewer should not be another place that “phones home.”

Private by designFile API only. No backend. No analytics.
One file, one jobEach viewer is a single self-contained HTML document.
Honest limitsSize caps and render budgets keep huge files from freezing the tab.
Export-friendlyCopy, CSV, JSON, HTML snapshots, unified diffs — ready for tickets.

Quick start

  1. Clone the repo or download a release/ZIP.
  2. Double-click any ksitools-*-viewer.html — or open this hub and pick a card.
  3. Drop a file. Nothing is uploaded.
  4. Optional local server: python3 -m http.server 8080
