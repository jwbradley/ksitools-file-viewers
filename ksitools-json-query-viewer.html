Examples & supported syntax cheat-sheet
Try these (click a row to load it into the query box):
  • . — identity (whole input)
  • .foo — field access (also .foo.bar, ."weird name", .["key"])
  • .[] — iterate an array / object values
  • .[] | .name — one field from each element
  • map(.x) — collect a field across an array
  • .[] | select(.age > 30) — filter
  • keys — sorted keys of an object
  • group_by(.type) — group elements by a key
  • .. | .id? — recursive descent, pull every id
  • .[] | select(.active) | .email
  • sort_by(.age) | reverse
  • gsub("a";"X") — regex replace (note the semicolon)
Supported: identity ., recursive descent .., field/index/slice/iterate (.foo, .[0], .[-1], .[1:3], .[], .[].foo), pipes |, commas ,, optional ?, object/array constructors ({foo: .bar}, [.[] | .id]), string interpolation " \(.foo) ", comparisons == != < <= > >=, logic and or, arithmetic + - * / %, and builtins: length keys values type not empty add first last to_number tostring ascii ascii_downcase ascii_upcase has contains unique sort sort_by group_by min max reverse floor ceil round split join ltrimstr rtrimstr test match gsub sub map select.
Not supported (intentionally omitted): def user functions, reduce/foreach, inputs, env, @base64/@csv format strings, --slurp, assignment |=/=/+=, limit, getpath/setpath/paths, if/then/else/end, as $var variables, recurse_down, // alternative operator, modules, imports.
