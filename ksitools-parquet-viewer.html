KSI Tools Parquet Viewer

Drop an Apache Parquet file
Pure-JS subset reader. Schema + paginated rows, decoded locally via the File API. Nothing is uploaded.
Supported features & known limits (pure-JS subset reader)
Supported compression: UNCOMPRESSED, GZIP (browser DecompressionStream), SNAPPY (pure JS).
Unsupported compression: ZSTD, BROTLI, LZ4, LZO, LZ4_RAW — columns using these are shown blank with an "(unsupported)" badge; other columns still display.
Supported value encodings: PLAIN, PLAIN_DICTIONARY / RLE_DICTIONARY, DELTA_BINARY_PACKED, DELTA_LENGTH_BYTE_ARRAY, DELTA_BYTE_ARRAY, BYTE_ARRAY_SPLIT.
Unsupported encodings: any other (e.g. RLE-only on non-dictionary data) — column shown blank with a badge.
Page types: DATA_PAGE (v1) and DICTIONARY_PAGE. DATA_PAGE_V2 handled best-effort (may fall back to blank column with a notice).
Schemas: flat and lightly nested (structs flattened with dot paths). Deeply nested LIST/MAP repetition is best-effort; repeated fields render as arrays when practical.
Logical types: UTF8, DECIMAL, DATE, TIMESTAMP (millis/micros/nanos, honoring isAdjustedToUTC), INTEGER, JSON, BSON, UUID — best-effort; falls back to the raw physical value.
Files are capped at 256 MB. Everything runs in your browser — no external calls, no network code of any kind.
