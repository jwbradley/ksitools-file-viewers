KSI Tools krb5.conf / keytab Viewer

Kerberos client config & keytab inventory — realms, KDCs, enctype policy, principal listing, weak-crypto detection — No external requests.

Never paste a binary keytab here. This tool reads krb5.conf text and the textual output of klist -ke <file> or ktutil list. Key material is never parsed, displayed, or exported — only principal names, KVNOs, and encryption-type names. A keytab file itself is equivalent to a password: keep it at mode 0600.
